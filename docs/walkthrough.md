# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。正常本地启动在数秒内完成。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功运行。

从首页选择一个检查批次，查看批次判定横幅、记录稳健距离图与记录级判定表，点击一条记录核对可疑单元格的原始测量值、关联预期与允许带；在“模型、证据与判断限制”核对模型指纹、近似重复列处理、共同观测不足的字段对与参照内极端记录。使用“查看原始记录”核对字段。需要比较某条记录保留、排除或修订的影响时，在“影响试算”填写记录与操作并查看判定变化（试算不落盘）；形成结论后在“复核意见”保存意见，会生成包含该意见的新数据版本，原始记录不变。输入会议名称并保存，然后改变所选范围；点击左侧刚保存的记录核对先前材料仍能打开，最后导出当前记录。整段交互通常需要60至90秒，不依赖远程请求。

`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。
