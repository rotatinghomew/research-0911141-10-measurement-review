# 数据口径

records 的 values 是字段测量值，null 是缺测；fields 定义单位和物理范围，范围内不代表统计上正常。batch=reference 为候选参照，不保证无污染；current、transfer 是待核对批次。reviews 记录行或单元格意见及可选修订值，不覆盖 records；没有异常真值标签，也没有预定必须命中的清单。

## 变量间关系复核

`multivariate.py` 在逐字段核对之外提供三级证据，方法全部先验固定：

- **拟合**：只用参照批次。字段按中位数与 MAD 标准化（量纲不同不受影响），相关用 Gnanadesikan-Kettenring 稳健估计，参照中混入少量错误时拟合仍稳定。稳健相关 |r|≥0.995 的近似重复列合并为代表列；相关矩阵做最近半正定修正。字段参照观测不足 8 条不入模；字段对共同观测不足 12 条按独立处理，并在“判断限制”中明确列出。
- **整记录**：每条记录在其实际观测到的字段子空间内计算稳健马氏距离，缺测不补零；与模型字段无共同观测的记录标记为“无法评估”而不是当作正常。行级阈值是卡方 0.99 分位（先验，随维度），参照留一法距离只用于经验 p、参照自检与批次漂移自助检验。任何阈值都不用待检批次校准。
- **单元格**：对每个观测格，用其余字段的条件分布给出关联预期与允许带（±3 条件尺度），标准化残差超限标记为可疑；解释始终带原始测量值、单位与预期区间。
- **批次**：待检批次距离中位数与参照留一法距离的自助分布比较，整体偏移时给出单条批次级结论和偏移字段，提示参照批次可能不再适用，而不是把整批读数报成大量坏样本。

复核意见通过叠加层影响拟合：decision=exclude 且 field 为空整条排除出参照拟合，field 非空则该格按缺测处理；revised_value 非空则该格以修订值参与拟合。其他 decision（如 investigate、confirm）只展示不影响拟合。评分永远使用原始测量值；试算（/api/whatif）是唯一例外且不落盘。异常提示不删除记录、不等于造假结论。

## 数据版本

`fixtures/data.json` 是可直接导入的一份完整材料，`product.json` 保存页面默认范围。导入必须提交完整对象，不把省略字段解释为删除补丁；以规范化 JSON 的 SHA-256 标识内容，同内容多次导入复用版本。原始记录只追加版本，保存的分析材料始终指向原来版本。保存复核意见会生成包含该意见的新数据版本，旧版本与原记录保持不变。

页面中的范围影响当前描述，不回写源数据。`null`、缺记录与实际零不能合并；数据格式问题应在导入时明确报错，而不是生成看似成功的空结果。涉及单位、时间或关系的解释以本文件为准，统计方法和业务决策没有预设结果。

## 目录

`measurement_review/domain.py` 提供现行领域校验和描述，`multivariate.py` 提供变量间关系复核，`validation.py` 处理基础引用与数值校验，`service.py` 连接领域操作和材料存档，`storage.py` 负责内容寻址数据与历史记录，`server.py` 提供本地接口。`web/app.js` 使用接口构建交互页面，不自行推导独立口径。
